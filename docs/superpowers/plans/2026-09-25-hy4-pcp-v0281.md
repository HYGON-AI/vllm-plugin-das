# Hy4 PCP on v0.28.1-dev Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve Hy4 with eight-card TP4/PCP2 and PP2/TP1/PCP4, preserving sink accuracy, MTP ownership and eager-only support.

**Architecture:** Extend the existing Model Runner V2 PCP config gate and HCU manager, rather than copying the v0.25.1 runner. Keep official KV allocation, PP broadcast and final-stage sampling restore; restore the global batch in the HCU adapter before non-final PP receive, because upstream v0.28.1 does not restore PCP on that path. Use the existing sparse FlashMLA implementation and add only ownership fixes demonstrated by failing tests.

**Tech Stack:** Python 3.10, installed OpenDAS vLLM v0.28.1-dev, PyTorch/HIP, HCU plugin, pytest, eight HCUs, OpenAI-compatible API and local HumanEval.

**Spec:** `docs/superpowers/specs/2026-09-25-hy4-pcp-v0281-design.md`

## Review Focus

- PCP prefill mixed with replicated MTP decode: only partitioned rows gather KV; replicated rows retain one copy (Task 2 ownership test).
- A short prompt with sink enabled: sparse MQA, not dense MHA, applies the sink on every token (Task 2 sink test).
- A PP2 non-final worker has no sampling hidden states: restore the saved global batch without attempting a hidden-state collective (Task 3 test).
- An MTP step with unequal accepted draft lengths: restore the target global batch exactly once before rebuilding draft metadata (Task 3 test and Task 4 live gate).
- PP partition starts on a shared indexer layer: reject the bad boundary before serving, rather than consuming a missing producer (Task 4 config and startup gate).

```python
def restore_for_sampling(
    self, hidden_states: torch.Tensor | None
) -> tuple[torch.Tensor | None, InputBatch]:
    assert self._global_batch is not None
    restored = (
        None if hidden_states is None
        else self.restore_hidden_states(hidden_states)
    )
    return restored, self._global_batch
```
